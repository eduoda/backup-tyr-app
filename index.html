backup-tyr

Ferramenta pessoal de backup.

Sincroniza um repositório restic já cifrado para o Google Drive do próprio autor, usando rclone. É uma cópia secundária: o repositório primário fica em object storage.

Uso

Aplicativo de uso pessoal e exclusivo do autor. Não há outros usuários, não há cadastro e não há interface para terceiros.

Acesso ao Google Drive

Usa apenas o escopo drive.file, que limita o acesso aos arquivos criados pelo próprio aplicativo. Documentos, fotos e demais arquivos da conta permanecem inacessíveis a ele.

Conteúdo enviado

Apenas blocos de dados cifrados pelo restic (AES-256). Nomes de arquivo, estrutura de diretórios e conteúdo são opacos no destino: sem a chave, mantida localmente, nada é legível.
